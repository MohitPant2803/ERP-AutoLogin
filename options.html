Automated OTP Handling

Configure how the extension automatically captures the 6-digit OTP sent by ERP.

1. Auto-Scan Open Webmail Tab (Recommended)

Silently captures the ERP OTP if Gmail (mail.google.com) or IIT KGP Webmail (iitkgpmail.iitkgp.ac.in) is open in any Chrome tab.

2. Auto-Detect Clipboard Copy

If you copy the 6-digit OTP code on your phone or notification, the extension immediately auto-detects, pastes, and submits it.

3. Local Python OTP Helper Server

Polls http://127.0.0.1:5000/otp if you run the companion python helper from iitkgp-erp-login.

4. Google OAuth & Gmail API (Autonomous OTP)

Directly connect your Google account to fetch the ERP OTP via Gmail API in 1 second, exactly like iitkgp-erp-login-pypi.
